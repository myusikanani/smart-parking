ABSTRACT / EXECUTIVE SUMMARY

Rapid urbanization and rising vehicle ownership have resulted in severe parking congestion, time loss, and air pollution in commercial zones, universities, and malls. Traditional parking management systems suffer from serious bottlenecks: reliance on paper tickets, lack of real-time slot visibility, manual fee collection, and vulnerable static passes that can be duplicated or shared.

ParkSmart is an end-to-end, responsive smart parking reservation and security gate management platform developed on the MERN stack (MongoDB, Express.js, React with TypeScript, Node.js). The system provides three integrated web portals tailored for Drivers, Parking Administrators, and Security Gate Staff.

Key engineering contributions of ParkSmart include:

  • Interactive 2D Slot Matrix: Provides drivers with real-time visual floor plans categorizing bays by vehicle type (Two-Wheeler, Four-Wheeler, EV Charging) with live occupancy status.
  • Cryptographic Dynamic QR Passes: Employs a time-synchronized HMAC-SHA256 token rotation algorithm (refreshing every 30 seconds) with a ±15-minute drift tolerance window to prevent screenshot re-entry fraud.
  • Smart Auto Gate Security Desk: Features an in-browser scanner with multi-camera fallback (rear/webcam/USB), screenshot photo upload decoding, continuous scanning mode, and automatic entry/exit state detection.
  • Automated Overstay Billing: Accurately calculates parking durations, base rates, and penalty fees for overdue vehicles without manual intervention.

Performance testing demonstrated an average QR pass verification speed of under 1.5 seconds, zero TypeScript compilation errors, and complete cross-platform responsiveness across mobile and desktop devices.

Keywords: Smart Parking System, MERN Stack, Dynamic QR Pass, HMAC-SHA256 Verification, Real-Time Slot Reservation, Smart Auto Gate Desk, Overstay Billing.

CHAPTER 1: INTRODUCTION

1.1 Background of the Project

Urban traffic congestion has become a critical challenge worldwide. Studies indicate that up to 30% of downtown traffic is caused solely by drivers searching for vacant parking spaces. Traditional parking systems rely heavily on manual attendants, printed thermal paper tickets, and manual cash handovers. This conventional setup results in long queues at entry points, billing inaccuracies, ticket loss, and no visibility into space availability prior to arrival.

1.2 Problem Statement

"To design, develop, and evaluate a responsive full-stack smart parking reservation and security gate access system that provides real-time slot booking for motorists, cryptographically secure dynamic QR gate access for security staff, and comprehensive financial/operational analytics for parking administrators."

1.3 Need / Motivation

  • Time and Fuel Efficiency: Eliminates blind cruising for parking by letting motorists reserve spaces in advance.
  • Gate Throughput: Fast, in-browser QR scanning reduces vehicle entry and exit time to under 2 seconds.
  • Fraud Prevention: Standard static QR codes can be screenshotted and shared. A rotating dynamic HMAC token ensures single-use validity.
  • Automated Revenue Control: Replaces manual estimation with exact timestamped billing and automatic overstay fee calculation.

1.4 Objectives

  1. Develop a modern, responsive single-page web app for slot discovery and booking.
  2. Create an interactive visual floor map reflecting real-time bay occupancy.
  3. Implement an HMAC-SHA256 rotating dynamic QR pass refreshed every 30 seconds.
  4. Build a versatile Security Gate Desk with multi-camera fallback, continuous scanning, and Smart Auto Entry/Exit handling.
  5. Design an Admin Dashboard for revenue monitoring, slot maintenance, and access auditing.

CHAPTER 8: SYSTEM IMPLEMENTATION

8.1 Dynamic QR Cryptographic Algorithm

To prevent pass duplication and unauthorized entry via screenshots, passes use a time-rotating token:

Token Format: PS-DYN|<bookingId>|<timeStep>|<hmacSignature>
• timeStep = Math.floor(currentTime / 30000) (Rotates every 30 seconds)
• hmacSignature = HMAC_SHA256(bookingId + ':' + timeStep, SECRET_KEY)
• Backend checks current timeStep ± 30 steps (±15 minutes) to handle client clock skew seamlessly.

8.2 Smart Auto Gate Security Desk

  • Direction Auto-Detection: When scanning a pass, the server checks vehicle status:
    • If status == 'confirmed' ➜ Grants Entry, marks slot occupied, and stamps check-in time.
    • If status == 'active' ➜ Grants Exit, frees the slot, and calculates overstay fees if due.
  • 1-Click Recovery: If an active car is scanned in manual Entry mode, the UI displays driver details with a single "Switch to EXIT & Allow Exit" button.
  • Continuous Scan Mode: Keeps the camera open for high-traffic gates with a 2.5-second debounce.
